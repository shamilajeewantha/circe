# circe_v3

`project.md` is the design source: a low-profile skid-steer autonomous inspection rover
(no wheel encoders, single horizontal camera, IMU, forward ToF, off-board VGGT-SLAM,
on-board YOLO, coverage-aware Next-Best-View loop).

**Gazebo milestone-1 simulation of this design lives in `simulation/` —
start at [`simulation/BUILD_GUIDE.md`](simulation/BUILD_GUIDE.md).**
