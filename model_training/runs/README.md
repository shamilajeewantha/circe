# model_training/runs/

Ultralytics output tree (`runs/detect/<name>/`), generated by `train.py`, `val.py`,
and `predict.py`. Each run holds `weights/{best,last}.pt` (+ `epochN.pt` when
`SAVE_PERIOD>0`), `args.yaml`, `results.csv`, plots, and TensorBoard event files.

Default run names (Ultralytics convention): training → `train/` (`train2`, ...),
validation → `val/`, prediction → `predict/`.

**Contents are gitignored** — everything except this README is excluded (weights and
plots are regenerable output, not source). The folder is kept so paths resolve.
Re-create by running the scripts in `model_training/`.
