Factory-floor inspection rover · dataset audit

Merged detection dataset — composition, balance & biases

Nine defect/asset classes assembled from 10 source datasets for a ground inspection robot. This is the pre-training audit: what the data is made of, where it is imbalanced, and what was dropped and why.

PRELIMINARY — counts are pre-deduplication and pre-resplit, computed directly from the verified source labels. The full report (UMAP embedding map + per-class sample mosaics + dedup-adjusted counts) is generated by pipeline/make_report.py after running the FiftyOne pipeline in drone_detect.

Class composition by source

Each bar is one class; segments show which source dataset contributed the boxes. Two things jump out: fluid_patch, smoke and fire dominate, and the structural classes (concrete_crack, efflorescence, exposed_rebar, spalling) come from a single source (CODEBRIM).

What was dropped — and why

Box-level drops (junk / wrong-target classes). Every dropped image is logged per-file in reports/dropped_images.csv; whole excluded folders are listed below.

  • excluded folder  gauge-face__kaushal-bhide — 2,897 images. Needle-endpoint labels only; no whole-dial box, so it cannot train gauge_face detection.
  • excluded folder  bolt-defects__ext-sdnet2025 — external, non-YOLO (CSV/JSON); outside the 9-class taxonomy.

Biases & caveats

  • Severe class imbalance (~48×). fluid_patch (38,847) vs efflorescence (808). Use class weights / oversampling; expect the rare structural classes to lag without more data.
  • Single-source domain risk. concrete_crack and all three structural classes come only from CODEBRIM (outdoor infrastructure imagery) — the model may overfit that domain. Collect factory-floor examples before deployment.
  • Fire/smoke includes outdoor/wildfire scenes — kept on purpose. Fire is fire; the training data is not restricted to indoor. Documented here rather than pruned.
  • Label quality. fluid-patch__welding-defects had a verified mislabel (a mouse pad boxed as oil) — flagged for spot-review. Junk classes (Other, object, gauge keypoints) were dropped.
  • Not covered by any data: damaged_conduit, exposed_wire, broken_torque_seal, clogged_vent (and overheating). These need custom staging and are absent from this merged set.
