# model_training/sample_downloaded_nuts/

Raw downloaded sample images (bolts/nuts, gauges, pipes, corrosion, etc.) used as an
ad-hoc `SOURCE` for `predict.py` smoke tests. The cleaned/curated version is in
`sample_downloaded_nuts_clean/`.

**Contents are gitignored** — everything except this README is excluded. The folder
is kept so the path resolves. These are throwaway test inputs, re-downloadable at will.
