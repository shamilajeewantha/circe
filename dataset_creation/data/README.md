# dataset_creation/data/

Working data for the `dataset_creation` subproject:

- `inputs/`  — raw input assets fed to the creation scripts
- `json/`    — intermediate/annotation JSON
- `outputs/` — generated results

**Contents are gitignored** — everything except this README is excluded (see the
root `.gitignore`). The folder is kept in git so the scripts' expected paths exist.
Regenerate the contents by re-running the `dataset_creation/src` pipeline.
